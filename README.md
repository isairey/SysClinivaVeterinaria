# 🐾 Sistema de Clínica Veterinaria (Visual Basic .NET)

Aplicación de escritorio desarrollada en **Visual Basic .NET (VB.NET)** orientada a la gestión de una clínica veterinaria.

---

## 🖥️ Descripción

Este sistema permite administrar la información de una clínica veterinaria mediante una interfaz de escritorio clásica, facilitando:

- Registro de mascotas 🐶🐱  
- Gestión de propietarios 👤  
- Control de citas 📅  
- Historial clínico 🩺  

Desarrollado utilizando Windows Forms para una experiencia sencilla y funcional.
