## 🚨 Reportar una Vulnerabilidad

Si encuentras una vulnerabilidad de seguridad, por favor sigue estos pasos:

1. **NO la publiques públicamente**
2. Envía un correo a:  
   📧 anonymus1201a@gmail.com
3. Incluye:
   - Descripción del problema  
   - Pasos para reproducirlo  
   - Evidencia (capturas o código)  

---

## ⏳ Tiempo de Respuesta

- 📩 Confirmación: 24–48 horas  
- 🔧 Solución: dependiendo de la gravedad  

---

## 🔒 Buenas Prácticas de Seguridad

Este sistema implementa medidas básicas como:

- Validación de datos de entrada  
- Protección contra inyecciones SQL  
- Manejo seguro de sesiones  
- Restricción de acceso por roles (administrador, veterinario, cliente)  

---

## ⚠️ Vulnerabilidades Comunes

Evitar:

- Exponer credenciales en el código  
- Uso de contraseñas débiles  
- Acceso no autorizado a información médica  

---

## 📌 Alcance

Este sistema maneja información sensible como:

- Datos de mascotas 🐶🐱  
- Datos de propietarios 👤  
- Historial clínico 🩺  

Por lo tanto, la seguridad es una prioridad.
